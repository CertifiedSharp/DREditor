# Selectable Items
Selectable Items are almost the same as regular Actors you can interact with. They're just Objects instead of characters.
## Auto Create Items in a Scene
- Menu Item: DREditor/Import/Items
- In the text area, simply list out the names of the items you want to have in the scene. 
- If you want to edit the body position (how the camera will look at an object when selected) you can check the "Add Cams to Bodies" box.
- Check the "Use Mesh Selection" box. Otherwise it will spawn invisible selectable boxes. 
- Click Import
- The selectable objects will then be spawned into the scene where you can now select and move them around.
- Remember to set all the body positions of each item. Once you've set them. Select the Menu Item: DREditor/Items/Remove Cameras.
- You can now plug in conversations for you items and use them for Room Building.
Note: Remember that you'll have to make a new progression flag if talking to an item is required in order to progress! **This will commonly be the case when selecting items that give the player truth bullets!**
