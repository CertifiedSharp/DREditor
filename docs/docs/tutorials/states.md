# States
## Difficulty State Database
- Somewhere in your project, create a folder called Difficulty.
- Right Click: Create/DREditor/States/Database
- Name it: Difficulty Database
- Right Click: Create/DREditor/States/Asset
- Duplicate the created asset twice (three in total)
- Select an asset and press F2 to rename.
- Rename them to: Kind, Normal, Mean. (You can name the difficulties whatever you want this is just in case you don't know what to name them.
- Fill out the name field on each asset with the name of the object.
- Click on your difficulty database and assign each asset to the database (in order of easiest to hardest difficulty).
