# Gates
Gates are the representation of a scene that the player can travel to. It is basically a data asset that contains the details relevant to traveling in between other scenes and the one the gate represents. 

## Gate Data
- **To Area Name**: The scene name corresponding with the gate.
- **Inv Gates**: Sometimes, during different phases of the game, like a murder investigation, scenes can become completely changed, warranting the need to have it become it's own separate scene. But, instead of just creating another gate, instead, you can set the chapter in which the investigation takes place and then the scene name to use during the investigation phase for that chapter. The gate will then redirect the player to that scene instead of the usual one. 
- **Is TPFD**: Check this box if the scene the gate represents is a Two Point Five D area. 
- **From Locations**: When we enter a scene managed by the gate, the system needs to know WHERE to place the player. _The location to place the player when coming from somewhere._ The "From Location". Setting From locations are made easy by just using a menu item command in combination with doors. For more information, see [Setting From Position on a 3D Door.](https://dreditor.net/docs/tutorials/roombuilding/createdoors.html#setting-the-from-position-on-a-3d-door) **Note that From locations do not need to be filled out if the above "Is TPFD" box is checked. **
- **Chapter Gates**: Sometimes, if there has been a massive change to the environment say for example, a generator blowing up a boiler room. If there is no clean up process, used narratively by your game, well from that point onward, that would be the default state of the scene, therefore, you can have the gate reroute the scene to use when the player has reached past a specific chapter and objective, and if they are past that point in progression to just always use that specific scene. 
- **Fast Travel Markers**: Later down the line, when or if you add a Map UI to your Pause Menu that enables you to fast travel. If you're coming from anywhere on the map, to a specific spawn location, the gate must have a list of positions to put the player when teleporting to the gate through fast traveling. Usually you can set this by just standing at the place for that marker, and copy over the position and rotation of the "Player" game object in the hierarchy under the Player_System.
