## What is DREditor?
The Death Row Editor, or DREditor. Is a Package library for the Unity game engine to allow users to make death-game style games without requiring the need to code. The engine is styled for visual novels/murder mystery investigation, the gameplay similarly found in games like Danganronpa, The Zero Escape series, Your Turn To Die, Ace Attourney, etc. Normally suited for Danganronpa fan games or "Fangans" since a majority of the gameplay possible with this engine can appear extremely true to the originals.

## Should you use DREditor?
DREditor is greatly suggested to projects and users who (are):
- New to unity.
- New to programming.
- Want to create a Fangan or death-game narritive that is a game or a video series.

It is extremely recommended that you have assets prepared a head of time, and while not required, there are no temporary assets, and you'll have to provide your own (or at least until some are added to the engine). Temporary assets are fine, but you'll find the best use to be with fully completed assets. 

Be warned though, this engine is not for the faint of heart. There's a LOT that goes into developing games like this. Even though DREditor allows for the increase in production of these kinds of games but they still usually take years in order to produce the necessary assets to complete even chapters. DREditor is simply a streamlined process that brings those assets together to create the desired game. 


If you feel like DREditor may not be right for your project, feel free to check out a list of [alternatives.](<https://dreditor.net/docs/alternativefangantools.html>)
